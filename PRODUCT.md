## Users

## Product Purpose

The ZuriLand website helps players join the Minecraft Survival server, learn about its community, and purchase available server products. Success means players can find the server connection details and complete a purchase through the existing cart and payment flow.

## Positioning

## Operating Context

Visitors use the public website to get the server address, explore the community, and browse the store. Registered players can sign in; store purchases use the website cart and existing payment providers.
